The objective was to separate cancellation-only host authority from executable terminal authority. The plan was to add one domain check to every normal execution consumer, retain the signed cancellation state for the cancellation consumer, and prove rejection before state mutation.

The correction adds an executable-domain predicate that requires normal cancellation state and the empty cancellation timestamp. Normal external dispatch, root relay import, nested relay import, cross-sidecar relay import, effective-context validation, and terminal response validation require this domain. The cancellation consumer continues to require the signed Cancelled state and exact cancellation timestamp. This prevents one signed authority from authorizing both cancellation consumption and executable terminal work.
